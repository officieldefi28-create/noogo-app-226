## 🚀 DÉPLOIEMENT EN 2 MINUTES

### Sur Votre Téléphone

**Android:**
1. Téléchargez `noogo-complete.zip`
2. Ouvrez le gestionnaire de fichiers
3. Trouvez le ZIP dans les téléchargements
4. Appuyez long → "Extraire" ou "Décompresser"
5. ✅ Dossier `noogo-complete` créé

**iPhone:**
1. Téléchargez `noogo-complete.zip`
2. Ouvrez l'app "Fichiers"
3. Allez aux téléchargements
4. Appuyez sur `noogo-complete.zip`
5. ✅ Dossier `noogo-complete` créé

### Sur GitHub

1. Allez sur votre repo: `github.com/votre-compte/noogo`
2. Cliquez "Upload files"
3. Sélectionnez **TOUS les fichiers** du dossier décompressé
4. Commit & Push
5. ✅ Vercel redéploie automatiquement

## 🆘 EN CAS DE SOUCI

**Erreur en décompressant:**
→ Téléchargez à nouveau le ZIP
→ Vérifiez qu'il fait 33 KB

**Loader ne disparaît pas:**
→ Attendez 3 secondes (fallback)
→ Videz le cache (Ctrl+Shift+R)

**Les images ne s'affichent pas:**
→ Vérifiez que `/produits` a les images JPG
→ Ouvrez F12 Network pour voir les erreurs

**Erreurs en console:**
→ Les warnings sont OK
→ Les erreurs ROUGES indiquent un problème
→ Lisez le message d'erreur
