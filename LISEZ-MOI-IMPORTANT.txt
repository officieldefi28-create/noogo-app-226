NOOGO — INSTRUCTIONS DE MISE EN LIGNE

Ce ZIP contient le site COMPLET avec :
- Le site de commande (index.html)
- L'espace Admin (admin.html)
- L'espace Partenaire (partenaire.html)
- La base de données automatique (dossier "netlify")

----------------------------------------
ÉTAPE UNIQUE OBLIGATOIRE
----------------------------------------

Si ce n'est pas déjà fait, ajoute 2 variables d'environnement sur
Netlify (Project configuration > Environment variables) :

  - ADMIN_PASSWORD
  - JETON_SECRET

Les valeurs exactes à utiliser t'ont été données directement dans
la conversation avec Claude — va les rechercher dans l'historique
du chat (elles ne sont volontairement PAS écrites dans ce fichier,
pour ta sécurité : ce fichier sera visible publiquement sur ton
site une fois en ligne).

----------------------------------------
COMMENT UTILISER LE SYSTÈME (ton travail quotidien)
----------------------------------------

★ ESPACE ADMIN (toi uniquement) :
  Adresse : https://noogodelice.netlify.app/admin.html
  Mot de passe : celui que tu as mis dans ADMIN_PASSWORD

  Dedans, tu peux :
  - Cliquer un seul bouton pour créer les 2 codes automatiques
    du mardi et du samedi (100 FCFA : 50 FCFA pour le client,
    50 FCFA de commission pour toi à distribuer si besoin)
  - Créer un nouveau partenaire (école, entreprise, particulier...)
    en remplissant un simple formulaire — un mot de passe est
    généré automatiquement, à donner au partenaire
  - Voir toutes les commandes en temps réel
  - Valider une livraison (c'est ce qui déclenche officiellement
    la commission du partenaire)
  - Marquer une commission comme payée une fois que tu as payé
    le partenaire

★ ESPACE PARTENAIRE (pour tes partenaires) :
  Adresse : https://noogodelice.netlify.app/partenaire.html
  Chaque partenaire se connecte avec SON numéro de téléphone
  et le mot de passe que tu lui auras donné.
  Il voit : son code, ses commandes, ses gains, son solde.

★ SITE CLIENT (pour tout le monde) :
  Adresse : https://noogodelice.netlify.app
  Les clients peuvent entrer un code promo avant de commander,
  et payer en Espèces, Orange Money ou Wave.

----------------------------------------
IMPORTANT À SAVOIR
----------------------------------------

- Les données (commandes, partenaires, gains) sont stockées en
  ligne et partagées entre tous les téléphones automatiquement.

- Une commission n'est comptée dans les gains d'un partenaire
  QUE lorsque tu valides la livraison dans l'espace Admin.

- Ce fichier ne contient jamais de mot de passe : uniquement le
  chat avec Claude les contient. Garde-les précieusement.
